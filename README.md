# netflix-ml-case-study
Netflix Viewer Preference Prediction and EDA

```
netflix-ml-case-study/
├── README.md
├── data/

│   └── processed/

│   └── figures/

  ```                                                  
## Folder Description

- **data/raw/** – Stores the original dataset.
- **data/processed/** – Stores cleaned and processed data.
- **notebooks/** – Contains Python notebooks for Exploratory Data Analysis (EDA).
- **reports/figures/** – Stores graphs and visualizations generated during EDA.
- **src/** – Contains reusable Python scripts.

## Project Objective

To analyze viewer preferences and movie-related data using Exploratory Data Analysis and Machine Learning techniques, and to propose a solution for personalized content recommendations.
